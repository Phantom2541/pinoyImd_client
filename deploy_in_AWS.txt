# Backend Deployment (Node.js API)

Connect to AWS:

```powershell
ssh -i "C:\Users\admin\.ssh\technowiz.pem" ubuntu@ec2-16-176-49-31.ap-southeast-2.compute.amazonaws.com
```

Run:

```bash
deploy-pinoyiMD
```

Or manually:

```bash
cd ~/PinoyiMD-server

git pull origin main

npm install

sudo systemctl restart pinoyimd.service
```

Verify:

```bash
systemctl status pinoyimd.service --no-pager
```

---

# Frontend Deployment (React Client)

## Step 1: Build Locally

Inside:

```text
pinoyIMD/client
```

Run:

```powershell
npm run build
```

Wait until:

```text
The build folder is ready to be deployed.
```

---

## Step 2: Upload Build Files

```powershell
scp -i "C:\Users\admin\.ssh\technowiz.pem" -r build\* ubuntu@ec2-16-176-49-31.ap-southeast-2.compute.amazonaws.com:/home/ubuntu/PinoyiMD-server/view/
```

---

## Step 3: Restart Service

SSH to AWS:

```powershell
ssh -i "C:\Users\admin\.ssh\technowiz.pem" ubuntu@ec2-16-176-49-31.ap-southeast-2.compute.amazonaws.com
```

Run:

```bash
sudo systemctl restart pinoyimd.service
```
